# 知乎热门AI文章爬取项目 - 开发计划与测试计划

## 一、需求分析

### 1.1 需求概述
- **核心功能**：每天定时查询知乎热门AI板块的10条文章链接，并保存到Excel文件
- **触发方式**：定时任务（每日执行）
- **数据来源**：知乎网热门AI相关话题/文章
- **输出格式**：Excel文件（含文章标题、链接、发布时间、摘要等信息）

### 1.2 功能需求
1. 定时执行：每天固定时间自动执行爬取任务
2. 数据爬取：从知乎网站获取热门AI文章列表
3. 数据筛选：提取前10条文章（按热度排序）
4. 数据存储：将数据保存为Excel格式
5. 日志记录：记录每次执行的结果和异常
6. 去重机制：避免重复保存相同文章

### 1.3 非功能需求
1. 稳定性：能够应对知乎网站结构变化
2. 异常处理：网络异常、数据格式变化等
3. 可配置：支持自定义爬取数量、执行时间等
4. 可追溯：保留历史数据版本

### 1.4 技术约束
- 开发语言：TypeScript + Node.js
- 定时任务：node-cron 或 similar
- 网页爬取：Puppeteer 或 axios + cheerio
- Excel操作：xlsx库
- 代码风格：遵循现有项目规范

## 二、开发计划

### 2.1 项目结构
```
src/
├── config/
│   └── config.ts          # 配置文件（爬取数量、执行时间等）
├── services/
│   ├── crawler.ts         # 知乎网页爬取服务
│   ├── excel.ts           # Excel读写服务
│   └── scheduler.ts       # 定时任务调度器
├── models/
│   └── article.ts         # 文章数据模型
├── utils/
│   └── logger.ts          # 日志工具
├── main.ts                # 程序入口
└── tests/
    └── *.test.ts          # 测试文件
```

### 2.2 开发阶段

#### 阶段1：基础架构搭建（1天）
1. 初始化项目结构
2. 安装依赖：
   - `puppeteer` 或 `axios` + `cheerio`（网页爬取）
   - `xlsx`（Excel操作）
   - `node-cron`（定时任务）
   - `dotenv`（环境变量）
   - `winston`（日志）
3. 创建配置文件 `config.ts`
4. 创建数据模型 `article.ts`

#### 阶段2：核心功能开发（2天）
1. **爬取服务开发** (`crawler.ts`)
   - 分析知乎热门AI页面的HTML结构
   - 实现文章标题、链接、发布时间提取
   - 实现热度排序逻辑
   - 添加请求头模拟和延时控制

2. **Excel服务开发** (`excel.ts`)
   - 实现Excel文件创建
   - 实现数据写入功能
   - 实现历史数据追加
   - 实现去重检查

3. **定时任务开发** (`scheduler.ts`)
   - 配置Cron表达式
   - 任务调度逻辑
   - 执行状态监控

#### 阶段3：异常处理与日志（0.5天）
1. 添加网络异常处理
2. 添加HTML结构变化检测
3. 实现日志记录
4. 添加错误通知机制（可选）

#### 阶段4：测试与优化（0.5天）
1. 单元测试编写
2. 集成测试
3. 性能优化
4. 代码审查
